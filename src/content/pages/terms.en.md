## What the service does

po ludzku shows GitHub tasks: whose move it is and what comes next. It reads data through the po ludzku GitHub App. It never writes anything to GitHub.

A public repository opens without sign-in, but only when its owner has installed the App. Private repositories open only after sign-in, if you have access to them on GitHub.

## Signing in through GitHub

You sign in through GitHub. Your browser stores one session cookie. It is HTTP-only and holds only a random identifier.

The server keeps your GitHub token in a Cloudflare Durable Object for at most 8 hours. Signing out deletes it immediately. We do not store a refresh token. When a session expires, you sign in again.

## Cache and avatars

Anonymous views of public repositories are cached for up to 60 seconds. The server checks access again before every response.

The server fetches avatars from GitHub and serves them from poludzku.info. Your browser never contacts GitHub.

## Tracking and cookies

We do not track. There is no analytics and there are no ads. The only cookie is the session cookie after sign-in.

## Personal data

The data controller for session data is Fundacja Serio. The legal basis is Article 6(1)(b) GDPR (running the session you ask for) and 6(1)(f) (security of the service).

You have the right to access your data and to have it deleted. You may also complain to the President of the Personal Data Protection Office (PUODO). Write to kontakt@serio.org.pl.
